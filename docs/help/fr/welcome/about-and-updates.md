# À propos de CD Draw

CD Draw est libre et open source. Cette page explique comment voir quelle version vous avez.

## La boîte À propos {#about}

Choisissez [[menu.help > menu.help.about]] pour voir la version utilisée,
l'auteur, la licence, un lien vers le code source et ce avec quoi le programme
est construit. Appuyez sur [[dialog.close]], <kbd>Entrée</kbd> ou
<kbd>Échap</kbd> pour la fermer.

![La boîte À propos de CD Draw](../../img/welcome-about-and-updates-about.png)

## L'écran d'accueil {#welcome-screen}

L'écran d'accueil est le premier onglet au démarrage de CD Draw. Il permet
de créer un dessin, d'ouvrir l'un des derniers dessins utilisés (chacun avec
une miniature ; [[menu.file.clear_recent]] les oublie), de partir d'un modèle,
de lire les nouvelles et de trouver des ressources d'apprentissage. Choisissez
[[menu.help > menu.help.welcome_screen]] pour le faire revenir.
[[menu.help > menu.help.video_tutorials]], [[menu.help.quick_start_guide]] et
[[menu.help.user_guide]] ouvrent sa page d'apprentissage, et
[[menu.help.whats_new]] ses nouvelles.

[[menu.help > menu.help.message_settings]] ouvre les options où se règlent
les messages de CD Draw.
