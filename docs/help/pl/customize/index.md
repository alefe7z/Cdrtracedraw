# Dostosowywanie i automatyzacja

CD Draw można ustawić pod swój sposób pracy: opcje programu i każdego
narzędzia, wygląd interfejsu, skróty klawiszowe, paski i obszary robocze.
Można też automatyzować pracę skryptami i śledzić czas poświęcony na rysunek.

Opcje są w [[menu.tools > menu.tools.options]]: każdy element otwiera własne
okno dialogowe. Zmiany widać od razu; [[dialog.ok]] je zachowuje, a
[[dialog.cancel]] przywraca wszystko. Przycisk **?** otwiera stronę tej Pomocy
o wyświetlanej stronie opcji.
