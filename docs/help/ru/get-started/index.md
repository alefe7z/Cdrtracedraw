# Начало работы

Эти страницы знакомят с CD Draw: части окна, создание, открытие и сохранение
рисунков, перемещение по рисунку и отмена действий, а также где найти помощь
во время рисования.

CD Draw работает в Windows, macOS и Linux, а также в веб-браузере без
установки. Это одна и та же программа; немногие отличия версии для браузера
описаны в [Версия для браузера](browser-version.md).
