# About CD Draw

CD Draw is free and open source. This page explains how to see which
version you have and how to bring back the Welcome Screen.

## The About box {#about}

Choose [[menu.help > menu.help.about]] to see the version you are running,
the author, the license, the address of the source code and what the program is
built with. Press [[dialog.close]], <kbd>Enter</kbd> or <kbd>Esc</kbd> to
close it.

![The About CD Draw box](../../img/welcome-about-and-updates-about.png)

## The Welcome Screen {#welcome-screen}

The Welcome Screen is the first tab when CD Draw starts. From it you can
create a drawing, open one of the drawings you used last (each shown with a
thumbnail; [[menu.file.clear_recent]] forgets them), start from a template,
read the news and find learning material. Choose
[[menu.help > menu.help.welcome_screen]] to bring it back.
[[menu.help > menu.help.video_tutorials]], [[menu.help.quick_start_guide]]
and [[menu.help.user_guide]] open its learning page, and
[[menu.help.whats_new]] its news.

[[menu.help > menu.help.message_settings]] opens the options where CD Draw's
messages are set.
