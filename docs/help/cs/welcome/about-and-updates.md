# O aplikaci CD Draw

CD Draw je svobodný a má otevřený zdrojový kód. Tato stránka vysvětluje, jak zjistit, kterou verzi máte.

## Okno O aplikaci {#about}

Zvolte [[menu.help > menu.help.about]] a uvidíte spuštěnou verzi, autora,
licenci, odkaz na zdrojový kód a z čeho je program postaven. Zavřete jej
tlačítkem [[dialog.close]] nebo klávesou <kbd>Enter</kbd> či <kbd>Esc</kbd>.

![Okno O aplikaci CD Draw](../../img/welcome-about-and-updates-about.png)

## Uvítací obrazovka {#welcome-screen}

Uvítací obrazovka je první karta po spuštění CD Draw. Z ní můžete vytvořit
kresbu, otevřít některou z naposledy použitých kreseb (každá s náhledem;
[[menu.file.clear_recent]] je zapomene), začít ze šablony, číst novinky a najít
výukové materiály. Zvolte [[menu.help > menu.help.welcome_screen]] a znovu se
zobrazí. [[menu.help > menu.help.video_tutorials]],
[[menu.help.quick_start_guide]] a [[menu.help.user_guide]] otevírají její
výukovou stránku a [[menu.help.whats_new]] novinky.

[[menu.help > menu.help.message_settings]] otevře volby, kde se nastavují
zprávy CD Draw.
