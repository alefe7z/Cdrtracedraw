# Přizpůsobení a automatizace

CD Draw lze nastavit podle toho, jak pracujete: volby programu a každého
nástroje, vzhled rozhraní, klávesové zkratky, panely a pracovní prostory.
Práci můžete také automatizovat skripty a sledovat čas strávený nad kresbou.

Volby najdete v [[menu.tools > menu.tools.options]]: každá položka otevře
vlastní dialogové okno. Změny se projeví hned; [[dialog.ok]] je ponechá a
[[dialog.cancel]] vše vrátí. Tlačítko **?** otevře stránku této nápovědy o
zobrazené stránce voleb.
