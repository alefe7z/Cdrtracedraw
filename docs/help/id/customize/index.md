# Kustomisasi dan otomatisasi

CD Draw dapat diatur sesuai cara Anda bekerja: opsi program dan setiap alat,
tampilan antarmuka, pintasan keyboard, bilah, dan ruang kerja. Anda juga dapat
mengotomatiskan pekerjaan dengan skrip dan mencatat waktu yang dihabiskan untuk sebuah
gambar.

Opsi ada di [[menu.tools > menu.tools.options]]: setiap item membuka kotak
dialognya sendiri. Perubahan langsung terlihat; [[dialog.ok]] menyimpannya dan
[[dialog.cancel]] mengembalikan semuanya. Tombol **?** membuka halaman Bantuan
ini tentang halaman opsi yang sedang tampil.
