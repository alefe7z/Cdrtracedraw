# Primeros pasos

Estas páginas presentan CD Draw: las partes de la ventana, cómo crear, abrir
y guardar dibujos, cómo moverse por un dibujo y deshacer el trabajo, y dónde
encontrar ayuda mientras dibuja.

CD Draw funciona en Windows, macOS y Linux, y en un navegador web sin
instalar nada. Ambos son el mismo programa; las pocas diferencias de la
versión para navegador se explican en
[La versión para navegador](browser-version.md).
