# Über CD Draw

CD Draw ist frei und quelloffen. Diese Seite erklärt, wie Sie sehen, welche Version Sie haben.

## Das Fenster Info {#about}

Wählen Sie [[menu.help > menu.help.about]], um die laufende Version, den Autor,
die Lizenz, einen Link zum Quellcode und die Grundlagen des Programms zu sehen.
Drücken Sie [[dialog.close]], <kbd>Eingabe</kbd> oder <kbd>Esc</kbd>, um es zu
schließen.

![Das Fenster Über CD Draw](../../img/welcome-about-and-updates-about.png)

## Der Begrüßungsbildschirm {#welcome-screen}

Der Begrüßungsbildschirm ist die erste Registerkarte, wenn CD Draw startet.
Von dort legen Sie eine Zeichnung an, öffnen eine der zuletzt verwendeten
Zeichnungen (jede mit einer Miniatur; [[menu.file.clear_recent]] vergisst sie),
beginnen mit einer Vorlage, lesen die Neuigkeiten und finden Lernmaterial.
Wählen Sie [[menu.help > menu.help.welcome_screen]], um ihn zurückzuholen.
[[menu.help > menu.help.video_tutorials]], [[menu.help.quick_start_guide]] und
[[menu.help.user_guide]] öffnen seine Lernseite, [[menu.help.whats_new]] seine
Neuigkeiten.

[[menu.help > menu.help.message_settings]] öffnet die Optionen, in denen die
Meldungen von CD Draw eingestellt werden.
