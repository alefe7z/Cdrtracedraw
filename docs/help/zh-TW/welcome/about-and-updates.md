# 關於 CD Draw

CD Draw 免費且開放原始碼。本頁說明如何查看你的版本。

## 關於方塊 {#about}

選擇 [[menu.help > menu.help.about]] 可查看執行中的版本、作者、授權、原始碼
連結以及程式的組成。按 [[dialog.close]]、<kbd>Enter</kbd> 或 <kbd>Esc</kbd>
關閉。

![關於 CD Draw 方塊](../../img/welcome-about-and-updates-about.png)

## 歡迎畫面 {#welcome-screen}

歡迎畫面是 CD Draw 啟動時的第一個索引標籤。你可以在這裡建立繪圖、開啟最近
使用的繪圖（每個都附縮圖；[[menu.file.clear_recent]] 會清除它們）、從範本
開始、閱讀新聞並找到學習資源。選擇 [[menu.help > menu.help.welcome_screen]]
可再次顯示它。[[menu.help > menu.help.video_tutorials]]、
[[menu.help.quick_start_guide]] 和 [[menu.help.user_guide]] 開啟它的學習頁面，
[[menu.help.whats_new]] 開啟它的新聞。

[[menu.help > menu.help.message_settings]] 開啟設定 CD Draw 訊息的選項。
