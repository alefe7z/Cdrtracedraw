# Introdução

Estas páginas apresentam o CD Draw: as partes da janela, como criar, abrir e
salvar desenhos, como se mover por um desenho e desfazer o que fez, e onde
encontrar ajuda enquanto desenha.

O CD Draw funciona no Windows, no macOS e no Linux, inteiramente no seu
computador: ele nunca se conecta à internet, e seus desenhos ficam onde você
os salva.
