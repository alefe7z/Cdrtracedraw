# Interface reference (owner's videos, October 2026)

What the owner's reference recordings of the program CD Draw follows show,
written down so every agent works from the same notes. How closely it
is followed, and what artwork is used, is the owner's decision
(`AGENTS.md`, rule 3). Items that need the internet, an account or AI are left out:
CD Draw is offline only (`AGENTS.md`, "Offline only").

The second video (87 s, 1280 x 698, recorded from a screen about 1.5
times larger) opens every menu of the menu bar in turn, then the toolbox
flyouts, the Properties docker with an object selected and the docker
list behind the "+" of the docker tabs. Sizes below are at 100 %
interface size (the video's pixels times 1.5).

## Menus

- Rows 22 px tall, text 12.5 px, the icon column about 26 px wide with
  16 px pictures, labels from 34 px, shortcuts right-aligned about 20 px
  from the edge, the submenu arrow at the edge. Separators are a thin
  line with 3 px above and below (7 px in all). Disabled rows are grey,
  their icons too. A check shows for a docker that is open or a view
  setting that is on; a dot for the current one of a choice (the view
  mode, the open drawing).
- The menu opens straight under its title, the title highlighted; moving
  along the bar with a menu open opens the next one.

## Toolbox flyouts

- A flyout is a list beside the button: each row the tool's picture,
  its name and its shortcut, rows 22 px, no check mark; the row under
  the pointer is highlighted. It opens on a press held on a button
  with a corner triangle, or a click on the triangle.
- Shapes: Polygon, Graph Paper, Spiral, Star, Impact Tool, Common
  Shapes. Rectangle: Rectangle F6, 3-Point Rectangle. Ellipse: Ellipse
  F7, 3-Point Ellipse. Curves: Freehand, 2-Point Line, Bézier Shift+F5,
  Artistic Media I, Pen Alt+C, B-Spline Alt+B, Polyline, 3-Point Curve.
  Smart: Smart Fill Ctrl+Alt+Space, Smart Drawing. Connectors: Anchor
  Editing, Connector. Effects: Blend Ctrl+Alt+M, Contour Shift+C,
  Distort... Eyedropper: Color Eyedropper Shift+G.

## Options (third video)

The third video (116 s) goes through Tools > Options page by page. One
dialog, titled "Options", about 802 x 676 px at 100 %.

- Header: the category's name in bold at the left; six square buttons
  at the right (Document, the program, Customization, Tools, Global,
  Workspaces), the current one filled blue. A click shows that category
  at its first page.
- Left: the page list, about 180 px wide, rows 25 px, the picked row a
  grey bar (not blue). Tools rows carry the tool's picture. Document has
  "Save as Default..." under the list; Workspaces lists the workspaces
  (a green check at the one in use) with "Import..." under it.
- Right: the page in a framed panel with its own scroll bar. Sections
  are a bold title with a thin line between sections; labels are
  right-aligned before their fields; tabs (Text, Printing, Guidelines)
  have the picked tab filled blue over a framed panel.
- Bottom: "?" at the left, OK (blue) and Cancel at the right.
- Pages. Document: General, Page Size, Layout, Background, Guidelines,
  Grid, Rulers, Save. The program: General, Tablet Mode, Display, Edit,
  Nodes and Handles, the clip frame page, the tracing page, Snapping,
  Save, Text, Pen Settings, Warnings, macros, Plug-ins. Customization:
  Appearance, Command Bars, Commands, Color Palette. Tools: Selection,
  Eraser, Zoom/Pan, Freehand/Bézier, Smart Drawing, Rectangle, Ellipse,
  Graph Paper, Spiral, Table, Dimension, Angular Dimension, Connector,
  Mesh Fill. Global: General, Printing, File Locations, File Formats,
  Color (user ID and privacy are left out: online).
- What each page holds, and what CD Draw does with it, is in
  `docs/behavior/options.md`. Controls without a CD Draw feature are
  shown greyed.
