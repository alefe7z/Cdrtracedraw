# Toolbar reference artwork

Isolated from the owner-supplied 1920 x 112 reference and the approved
subpixel-rounded contour reconstruction (0.23 px corners). Paths only;
no embedded raster, fonts, labels or document values. Background removed
and coverage normalized so the live control supplies theme/disabled tint.
The low-resolution source limits recoverable detail; these are not the
original application vectors. Existing commands and numeric fields remain
interactive. Unmapped icons keep their existing artwork.
