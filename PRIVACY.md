# Privacy policy

CD Draw is a vector editor that runs entirely on your own computer. This
policy covers the desktop program (installer, portable zip, Microsoft
Store, macOS and Linux packages) and `tracedraw-cli`.

## What CD Draw collects

Nothing. CD Draw has no accounts, no telemetry, no analytics, no crash
reporting, no advertising and no online services. It never connects to
the internet or to any other computer: it checks for no updates, downloads
nothing, uploads nothing and opens no network port. The program contains
no networking code at all.

## What stays on your computer

- Your drawings, where you save them.
- Preferences, the Shelf and thumbnails of recent drawings, in
  CD Draw's preferences folder. Deleting that folder removes them;
  Options > Global > Reset all settings puts the preferences back as they
  came.
- Automatic backups of open drawings, in the folder set in Options > Save
  (by default a `CD Draw` folder in your system's temporary folder).

Preferences saved by an older version that had online features (AI service
keys, a GitHub token, the update check) are read without those parts, and
they are left out the next time the preferences are saved.

## When CD Draw hands something to another program

Only when you ask it to, and only to programs on your computer:

- Help opens the copy of the Help installed with CD Draw in your web
  browser, from disk.
- Send To > Mail hands a file to your mail program; you choose whether to
  send it.
- Edit Bitmap opens a picture in the editor you choose; printing opens
  the print PDF in your system's viewer.
